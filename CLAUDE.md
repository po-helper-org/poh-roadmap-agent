# poh-roadmap-agent — инструкции агенту

Репозиторий — методология и навыки: ведёшь PO шаг за шагом к визуальному Roadmap целевых состояний, реестру вопросов,
беклогу «кто что делает» и .xlsx для руководства.

Начни с навыка `roadmap-methodology` (`.claude/skills/roadmap-methodology/SKILL.md`): он определяет этап и навык этапа.
Есть `HANDOFF.md` — прочитай его первым.

## Правила

- **Только из источников:** слова PO, файлы `sources/`, ответы названных людей. Нет источника — поле пустое и «в
  источниках не описано»; свой вывод — «предложение агента», в файлы после «да» PO.
- **Ответственных, сроки, критичность и исполнителей назначает только PO.**
- **Правки PO переносишь дословно;** каждую реплику PO — в `sources/po-messages.md` с датой.
- **Ты пишешь только md, `questions.csv` и `journal.csv`** (журнал — только дописываешь, командой `bin/roadmap journal
  add`; ответ на вопрос — `bin/roadmap question answer`). `roadmap.json`, `roadmap.html`,
  .xlsx и письмо строит `bin/roadmap` детерминированно; руками их не правишь.
- **После каждого шага:** `bin/roadmap lint <папка>` — «Принято», `bin/check-qlinks <папка>` — «Нарушений: 0»,
  `bin/roadmap build <папка цели> -o roadmap.html`, коммит на русском с сутью правки, отчёт PO с пробелами.
- **Бэкап — только `bin/backup <out.zip> [доп. папки]`.** В конце каждой сессии — `HANDOFF.md` (навык `roadmap-10-backup`).
- **Дейлик — навык `roadmap-11-daily`, промпт расписания `templates/daily-brief.md`:** один запуск — один отчёт
  `bin/roadmap daily <папка цели> --date <сегодня>`, руками не правишь, прошлые отчёты не трогаешь.
- Статус «Выполнено» — только когда известно, кто, когда и где принял.

## Куда смотреть

- Оформление ЦС, шага, подзадачи, вопроса — `.claude/skills/okr-roadmap-viz/resources/constitution.md`.
- Формат файлов — `.claude/skills/okr-roadmap-viz/resources/format.md`.
- Эталон результата — `examples/school-migration/` (структура и плотность; данные не копировать).
- Шаблоны — `templates/`; сценарии роя — `templates/workflows/`.
- Примеры «плохо → хорошо» — `docs/methodology.md`.
- Меняешь код инструмента — `python3 -m unittest discover -s .claude/skills/okr-roadmap-viz/scripts`; только stdlib.
- Публичный репозиторий: реальные имена, компании, сроки и договорённости в него не коммить — работа PO идёт в его
  приватной копии. Перед коммитом сюда — `bin/check-anon` (свой список слов — `.anon-denylist`, пример
  `.anon-denylist.example`).
- Связанный репозиторий: квартальное планирование и исполнительный контроль PO — `poh-okr-agent`. Просят цели квартала,
  TeamPlanner или экватор — предложи его; этот репозиторий — стратегический Roadmap для R&D и стратегии.
