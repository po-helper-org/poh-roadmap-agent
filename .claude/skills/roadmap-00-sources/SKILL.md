# Этап 0. Источники и рамка

Правило «только из источника» работает, только если у каждого будущего факта есть файл. Этот этап создаёт эти файлы.
Сквозные правила — навык `roadmap-methodology`.

## Вход

Материалы PO: выгрузка Ганта или WBS, план трека, протоколы созвонов, документы, письма; состав команды.

## Делаешь

1. Кладёшь каждый материал отдельным файлом в `sources/`. Архив созвонов — папкой с `README.md` «как читать».
2. Выгрузку WBS переводишь в чистую таблицу `sources/wbs.tsv` (код, название, уровень, начало, окончание): код и
   название берёшь **внутри одного узла** выгрузки. Сверяешь 5–10 кодов с исходником глазами.
3. План трека — в таблицу `sources/plan.tsv` (номер, задача, роль, начало, окончание, статус), номера — как в исходнике
   PO (рекомендация: в исходном проекте план лежал html-выгрузкой, и номера приходилось сверять с ней вручную).
4. Состав команды и зоны ответственности — словами PO в `sources/po-messages.md` (шаблон —
   `templates/po-messages.md`). Туда же — каждая следующая реплика PO с датой.
5. `bin/roadmap init .okr/roadmap/<slug> --title "Цель NN. <название>"`. Несколько стримов — папка на стрим и папка
   цели (навык `roadmap-07-business-goals`).

## Спрашиваешь PO

Одним сообщением, не больше трёх вопросов: как называется цель; какой трек свой; что важнее, если источники спорят;
кто за что отвечает, если состава нет.

## Промпт PO

```
Работай по методологии poh-roadmap-agent. Начинаем планирование цели «<название>».
Материалы: <файлы>. Состав команды: <роль — зона ответственности, по строке>.
Ничего не выдумывай: чего нет в материалах — скажи списком.
```

## Ошибки, которые PO поправлял

- Наивный парсинг XML Ганта сдвинул коды WBS относительно названий на одну позицию → сопоставляй поля внутри узла,
  держи `wbs.tsv`.
- Номер вехи плана взят из промежуточной модели агента → номера и даты плана сверяй только с исходником PO.

## Готово, когда

- [ ] Каждый материал PO лежит файлом в `sources/`
- [ ] `wbs.tsv` и `plan.tsv` есть, коды совпадают с названиями
- [ ] Состав команды и зоны записаны словами PO в `sources/po-messages.md`
- [ ] Папка карты создана `bin/roadmap init`, `bin/roadmap lint` — «Принято»
- [ ] Коммит; отчёт PO со списком того, чего в материалах нет

Дальше — этап 1, навык `roadmap-01-goals`.
