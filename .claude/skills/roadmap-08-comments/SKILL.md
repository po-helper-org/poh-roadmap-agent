# Этап 8. Комментарии PO и журнал прогресса

PO смотрит страницу и правит её мышью и комментариями. Страница ничего не пишет в репозиторий сама: правки приходят
промптом «Скопировать промпт» или файлом `PENDING.md` из архива «Экспортировать». Формат журнала — `format.md`, раздел
«Журнал комментариев и прогресса»; порядок разбора — `okr-roadmap-viz/SKILL.md`, этап 4.

## Делаешь

1. Правки страницы (даты, статусы, роли, зависимости, новые задачи, порядок) переносишь в md как есть, словами PO.
2. Строки «Журнал …» из промпта или `PENDING.md` — готовые строки CSV: дописываешь их **в конец** `journal.csv` указанной
   папки (UTF-8 с BOM, CRLF). Строку, которая уже есть, не повторяешь. Старые строки не правишь и не удаляешь.
3. Прогресс задачи — строка «прогресс» (0…100 и статус); тем же значением обновляешь `progress`/`status` во frontmatter,
   иначе `lint` предупредит. Пример — `examples/school-migration/.okr/roadmap/courses/journal.csv` и `s11`.
4. Комментарий PO — ещё и поручение: просит изменить дату, задачу или вопрос — делаешь правку в md или `questions.csv`;
   отвечаешь строкой «комментарий» с автором «агент», если нужно.
5. Комментарии разбираешь по номерам: что просят, в каком файле, что меняешь. Неясно — вопрос PO в отчёте, не угадываешь.
6. Номера в промпте — на момент той сборки: ищешь задачу по файлу или `id`.
7. `lint` → `check-qlinks` → `build` → коммит → отчёт по номерам.

## Статусы — по доказательству

PO пишет «утвердили» или «сделано» — ставишь «Выполнено» только когда известно кто, когда и где принял. Иначе — вопрос
PO и строка «комментарий» в журнале.

## Промпты PO

```
<вставленный промпт со страницы: комментарии, правки, строки журнала>
```

```
Вот архив со страницы: <файл.zip>. Перенеси правки и журнал в репозиторий.
```

## Ошибки, которые PO поправлял

- Комментарии и прогресс жили только в браузере и терялись → журнал `journal.csv` у каждого стрима: страница →
  архив → пересборка, собирается детерминированно.
- Новые комментарии дописывались в «## Комментарии» md → пиши их в `journal.csv`; старые в md не переноси без просьбы PO.

## Отчёт

```
По комментариям: 1 — сделано (<файл>), 2 — вопрос: <…>, …
Правки страницы: перенесено N. Журнал: дописано N строк в <папка>/journal.csv.
Страница: <путь>, коммит <sha>.
```

## Готово, когда

- [ ] Каждая правка страницы перенесена в md или `questions.csv`
- [ ] Строки журнала дописаны в конец своих `journal.csv` без повторов; frontmatter совпадает с последним прогрессом
- [ ] Каждый комментарий — «сделано» или вопрос PO
- [ ] `lint` — «Принято» без расхождений журнала, `check-qlinks` — 0, страница пересобрана, коммит
