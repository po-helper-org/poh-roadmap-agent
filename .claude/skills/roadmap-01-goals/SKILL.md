# Этап 1. Целевые состояния словами PO

Начинаешь с чистого листа: на карте только цели PO и их даты. Всё остальное приходит потом и под конкретную цель.
Формат ЦС — `constitution.md`, статьи I.6 и II.1; шаблон — `templates/backlog/ts.md`.

## Делаешь

1. Заводишь каждое ЦС файлом `backlog/ts<N> - <суть>.md`: `title: "<N>. <формулировка PO дословно>"`, `role: PO`,
   `ordinal: <N>`, `short: "<N> · <суть>"` (сокращение без новых слов — показать PO).
2. Дату ставишь по форме статьи I.6: веха плана с номером; «Даты в плане нет. Решения, от которых зависит: …»;
   предварительное окно PO с `estimate: не подтверждена`; или строка о пустоте источников.
3. Больше на карте ничего нет: ни условий, ни фич, ни блокеров, ни шагов.
4. `lint` → `build` → коммит → отдаёшь PO страницу.

## Спрашиваешь PO

- список ЦС его словами и порядок;
- на какой дате держится каждая;
- с какого ЦС начинаем (оно станет эталоном).

## Промпт PO

```
Создай чистую карту: только целевые состояния и их даты, больше ничего.
1. <формулировка ЦС 1>
2. <формулировка ЦС 2>
Даты возьми из <плана / моих слов>. Покажи страницу.
```

## Ошибки, которые PO поправлял

- Перерисовал страницу в своём стиле («Очень перемудрённая диаграмма») → один инструмент и один вид страницы, вид
  меняется только комментарием PO.
- Завёл условия по всем трекам, когда PO интересовал один стрим («Убери все условия, нас сейчас интересует только стрим
  целевых состояний») → начинай с минимума, который назвал PO.
- Принёс пакет руководству без декомпозиции — PO вернул к карте → пакет строится из карты (этап 9), а не вместо неё.

## Готово, когда

- [ ] ЦС — формулировки PO дословно, номера и порядок PO
- [ ] Дата каждой ЦС с основанием или «даты нет»
- [ ] На карте нет условий, фич, блокеров
- [ ] PO увидел страницу и подтвердил список
