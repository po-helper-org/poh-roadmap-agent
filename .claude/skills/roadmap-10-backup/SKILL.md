# Этап 10. Бэкап и передача

Ничего не теряется: коммит после каждого такта, реплики PO в `sources/po-messages.md`, архив по запросу и перед
сменой инструмента, `HANDOFF.md` для следующего агента.

## Бэкап

Только скриптом:

```bash
bin/backup <out.zip> [доп. папки] [--name <корневая папка в архиве>] [--max-mb 20]
```

Скрипт кладёт репозиторий с историей git, сжимает историю (`git gc`), пишет кириллические имена с признаком UTF-8,
сохраняет пустые папки git, отказывается при `: ? * " < > | \` в именах файлов, проверяет распаковку, `git fsck` и
размер ≤ 20 МБ. Ручной `zip` давал на macOS «Ошибка 94», а файлы больше ~25 МБ обрезались при скачивании.

Делаешь бэкап, когда:
- PO просит («сделай бэкап», «выгрузи .zip»);
- перед переходом в другой инструмент или на другой компьютер;
- после крупного этапа (рекомендация).

Вместе с репозиторием PO может приложить архив кнопкой «Экспортировать» на странице (`RESTORE.md`, `map/`,
`PENDING.md`) — он несёт несохранённые правки браузера (навык `roadmap-08-comments`).

## Передача

1. `HANDOFF.md` по шаблону `templates/HANDOFF.md`: что это, папки и треки, ЦС и что разложено, реестры (сколько
   вопросов, открытых, без ответственного), открытые решения PO, источники, как продолжить, бэкап. Коротко, без
   истории попыток. **Обновляешь в конце каждой сессии**, а не только при передаче: сессию может продолжить другой
   агент или инструмент без предупреждения. Последний коммит сессии — с актуальным `HANDOFF.md`.
2. `AGENTS.md` — для агента без навыков Claude Code: те же правила, что в `CLAUDE.md`, и прямые пути к `SKILL.md`
   навыков (автозагрузки там нет).
3. `roadmap.html` в корне — актуальный: `bin/roadmap build .okr/roadmap/<цель> -o roadmap.html`.
4. Имена файлов без `: ? * " < > | \`.

## Промпты PO

```
Сделай бэкап — хочу продолжить в <Codex / на другом ноутбуке>.
```

```
Обнови HANDOFF: текущее состояние и открытые вопросы, чтобы следующий агент продолжил.
```

## Ошибки, которые PO поправлял

- Архив не открывался на macOS («Ошибка 94») → только `bin/backup`.
- «Где .html для просмотра?» → `roadmap.html` в корне репозитория, открывается без сети.
- Имена файлов с «:» и «?» не распаковывались → такие символы из имён убраны.

## Готово, когда

- [ ] .zip собран `bin/backup`, проверки скрипта OK, размер ≤ 20 МБ
- [ ] Архив распаковывается в пустую папку, `bin/roadmap build` собирает карту
- [ ] `HANDOFF.md`: состояние, открытые решения PO, следующий шаг — обновлён в этой сессии
- [ ] `AGENTS.md` актуален; `roadmap.html` в корне пересобран
- [ ] Коммит; PO получил путь к архиву
