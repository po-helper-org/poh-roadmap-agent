# poh-roadmap-agent

Методология и набор навыков Claude Code, по которым агент шаг за шагом ведёт человека к проработке сложной цели:
**визуальный Roadmap** целевых состояний (один html), **реестр вопросов**, **беклог «кто что делает»** и единый
**.xlsx для руководства** с письмом.

Для кого: владелец цели (PO, продакт, руководитель проекта), у которого есть сырые материалы — выгрузка Ганта или WBS,
план, протоколы созвонов — и нет времени собирать из них карту, вопросы и пакет руководству вручную.

Методология выведена из реального проекта (три дня, около 70 коммитов, больше сотни реплик PO) и обезличена:
системы — «контур А» и «платформа Б», люди — роли.

## Быстрый старт

1. Сделайте свою **приватную** копию репозитория: в неё пойдут ваши реальные материалы, имена и сроки.
   ```bash
   git clone <адрес вашей копии> my-roadmap && cd my-roadmap
   ```
2. Откройте папку в Claude Code и скажите:
   ```
   Работай по методологии poh-roadmap-agent. Цель — «<название цели>».
   Материалы: <приложите файлы>. Состав команды: <роль — за что отвечает, по строке>.
   ```
3. Дальше агент сам ведёт по этапам: на каждом предлагает, спрашивает вас и записывает только то, на что вы ответили
   «да». Откройте `roadmap.html` в браузере и комментируйте прямо на странице.

Нужен только Python 3 (стандартная библиотека). Codex и другие агенты — читают `AGENTS.md`.

## Этапы и что получается на выходе

Каждый этап — свой навык; агент вызывает его сам по вашим словам или по порядку. Главный навык —
`roadmap-methodology`: он определяет, на каком вы этапе, и ведёт дальше.

| № | Этап | Скажите агенту | Навык | Артефакт на выходе |
|---|---|---|---|---|
| 0 | Источники и рамка | «вот материалы», «начинаем планирование» | `roadmap-00-sources` | `sources/` (WBS и план таблицами, реплики PO, состав команды), папка карты |
| 1 | Цели словами PO | «собери цели» | `roadmap-01-goals` | чистая страница: только целевые состояния и даты |
| 2 | Путь объекта — шаги | «разложи цель на шаги» | `roadmap-02-path` | шаги ЦС, ЦС — полоса на шкале |
| 3–4 | Реестр вопросов | «заведи вопросы», «детализируй вопросы» | `roadmap-03-questions` | `questions.csv`: точечные вопросы с ожидаемым ответом, источником, «Влияет на» |
| 5 | Полнота и ценность | «проверь полноту», «провалидируй роем» | `roadmap-05-completeness` | вердикт по каждому шагу, «внесу механически» / «решить PO» |
| 6 | Подзадачи с ролями, эталон | «разложи на подзадачи», «зафиксируй эталон» | `roadmap-06-subtasks` | беклог: подзадачи с ролью, исполнителем, принимающим, DoD, HowToDemo |
| 7 | Цели как бизнес-эффект, стримы | «переформулируй цели для бизнеса», «вынеси в отдельный стрим» | `roadmap-07-business-goals` | короткие формулы целей, папки стримов, сборная карта |
| 8 | Комментарии и журнал | вставьте промпт со страницы | `roadmap-08-comments` | правки в md, `journal.csv` |
| 9 | Пакет руководству | «сделай xlsx для руководства» | `roadmap-09-leadership-pack` | .xlsx (Roadmap · ГАНТТ · Реестр вопросов · Беклог задач) и письмо |
| 10 | Бэкап и передача | «сделай бэкап», «передай работу» | `roadmap-10-backup` | .zip для macOS, `HANDOFF.md` |

Этапы 2–6 проходятся по каждой цели; первая разобранная цель становится эталоном для остальных. Полный текст
методологии с примерами «плохо → хорошо» и историей проекта — [`docs/methodology.md`](docs/methodology.md).

## Пример результата

[`examples/school-migration/`](examples/school-migration/) — вымышленная цель «Переезд онлайн-школы на платформу Б»:
два стрима на одной сборной карте, 4 целевых состояния, 26 задач, 20 вопросов, журнал, решения PO и письмо руководству.

```
examples/school-migration/
  sources/po-messages.md, wbs.tsv, plan.tsv        источники: всё на карте восходит к ним
  .okr/roadmap/goal-01/roadmap.md                  сборная карта: Трек 1 → ../courses, Трек 2 → ../corporate
  .okr/roadmap/courses/                            ЦС1 (эталон: путь курса 1.1–1.4), ЦС2 (бизнес-цель), ЦС3 (веха)
  .okr/roadmap/corporate/                          стрим, выделенный из courses
  reports/Решения_PO_18.11.2026.md, Письмо_руководству_19.11.2026.txt
```

```bash
bin/roadmap build examples/school-migration/.okr/roadmap/goal-01 -o /tmp/school.html    # откройте в браузере
bin/roadmap xlsx  examples/school-migration/.okr/roadmap/goal-01 -o /tmp/school.xlsx --date 2026-11-19
```

## Устройство репозитория

```
CLAUDE.md, AGENTS.md            короткие инструкции агенту (Claude Code; Codex и другие)
.claude/skills/
  roadmap-methodology/          главный навык: этапы, сквозные правила, когда рой и бэкап
  roadmap-NN-<этап>/            навык этапа: что делать, вопросы PO, промпты, ошибки, чек-лист приёмки
  okr-roadmap-viz/              инструмент: md → проверка → html, .xlsx, письмо
    resources/constitution.md   как оформлять цель, шаг, подзадачу, вопрос (эталон — пример)
    resources/format.md         формат roadmap.md, backlog/*.md, questions.csv, journal.csv
docs/methodology.md             методология для человека
templates/                      шаблоны: паспорт, ЦС/шаг/подзадача, questions.csv, journal.csv, решения PO, письмо, HANDOFF, сценарии роя
examples/school-migration/      сквозной пример
bin/roadmap, check-qlinks, backup
```

Ваша работа появится рядом: `sources/` — материалы, `.okr/roadmap/<slug>/` — карта, `reports/` — пакет руководству,
`roadmap.html` — главная страница.

Почему так: навык на этап держит в контексте агента только то, что нужно сейчас, и вызывается вашими словами;
конституция и формат — общие для всех этапов и лежат при инструменте; пример — единственный эталон, на который
ссылаются конституция и навыки, поэтому агент копирует структуру и плотность, а не данные.

## Команды

| Команда | Что делает |
|---|---|
| `bin/roadmap init <папка> --title "…"` | заготовка новой карты |
| `bin/roadmap lint <папка>` | проверка md и csv, граф `roadmap.json` |
| `bin/roadmap build <папка> [-o roadmap.html]` | страница; папка цели со стримами — сборная страница |
| `bin/roadmap tree <папка>` | дерево задач с номерами и зависимостями |
| `bin/roadmap questions <папка> [<id>] [--open]` | реестр вопросов текстом |
| `bin/roadmap xlsx <папка> -o <файл.xlsx> [--track N] [--goals 1,2] [--date ГГГГ-ММ-ДД]` | пакет руководству, 4 листа |
| `bin/roadmap letter <папка> -o <письмо.txt> [--track N] [--date …] [--xlsx <имя>]` | письмо к .xlsx |
| `bin/check-qlinks <папка>` | каждый `Q-NN` из текста задачи стоит в «Влияет на» задачи или предка |
| `bin/backup <out.zip> [доп. папки]` | бэкап, который открывается на macOS |
