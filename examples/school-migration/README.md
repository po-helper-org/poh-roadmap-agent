# Пример: переезд онлайн-школы на платформу Б

Сквозной вымышленный пример результата методологии. Домен, роли и данные придуманы; совпадения случайны.
Плотность и стиль — как в реальном проекте, из которого выведена методология.

Онлайн-школа переезжает со старой платформы обучения (**контур А**) на новую (**платформа Б**). Объект, чей путь
раскладывается, — **курс** (ЦС1) и **ученик** (ЦС2).

## Что где

| Файл | Этап методологии | Что показывает |
|---|---|---|
| `sources/po-messages.md` | 0, все | реплики PO дословно с датой — источник для каждого поля карты |
| `sources/wbs.tsv`, `sources/plan.tsv` | 0 | чистые таблицы WBS и плана: коды и окна, на которые ссылаются «Основа» и «Основание даты» |
| `.okr/roadmap/goal-01/roadmap.md` | 7 | сборная карта цели: два трека ссылаются на папки стримов |
| `.okr/roadmap/courses/` | 1–6 | стрим «Курсы и ученики»: ЦС1 — эталон (путь курса 1.1–1.4, подзадачи WBS и плана), ЦС2 — бизнес-цель с «Образом результата» и шагом решений бизнеса 2.1, ЦС3 — веха без источников |
| `.okr/roadmap/corporate/` | 7 | стрим «Корпоративные клиенты», выделенный из стрима курсов: id задач прежние (`ts4`, `s41…`), номера в названиях — новые; предварительное окно PO, шаги без дат |
| `*/questions.csv` | 3–5 | 20 вопросов: точечные, с ожидаемым ответом, источником, «Влияет на», историей; снятый Q-05 и объединённый Q-12 — пропуски нумерации; Q-15 — общий вопрос двух реестров |
| `courses/journal.csv` | 8 | прогресс задачи и комментарий к вопросу; `corporate/journal.csv` — только заголовок |
| `reports/Решения_PO_18.11.2026.md` | 5–7 | решения за PO: варианты и рекомендация агента |
| `reports/Цель01_Курсы_и_ученики_Roadmap_19.11.2026.xlsx` | 9 | пакет руководству по стриму «Курсы и ученики»: Roadmap · ГАНТТ · Реестр вопросов · Беклог задач — вывод `bin/roadmap xlsx … --track 1 --date 2026-11-19` |
| `reports/Письмо_руководству_19.11.2026.txt` | 9 | письмо к этому .xlsx — вывод `bin/roadmap letter … --track 1 --date 2026-11-19 --xlsx <имя .xlsx>` |

## Проверка

```bash
bin/roadmap lint examples/school-migration/.okr/roadmap/goal-01      # «Принято», 9 предупреждений
bin/check-qlinks examples/school-migration/.okr/roadmap/goal-01      # «Нарушений: 0»
bin/roadmap build examples/school-migration/.okr/roadmap/goal-01 -o /tmp/school.html
bin/roadmap xlsx  examples/school-migration/.okr/roadmap/goal-01 -o /tmp/school.xlsx --track 1 --date 2026-11-19
bin/roadmap letter examples/school-migration/.okr/roadmap/goal-01 -o /tmp/school.txt --track 1 --date 2026-11-19 \
  --xlsx Цель01_Курсы_и_ученики_Roadmap_19.11.2026.xlsx   # совпадает с reports/Письмо_руководству_19.11.2026.txt
```

Ожидаемые предупреждения `lint`: «веха без даты» у `ts3` (форма ЦС без источников) и 8 «открытый вопрос без
ответственного» — ответственных назначает только PO, пробел вынесен в `reports/Решения_PO_18.11.2026.md`.
